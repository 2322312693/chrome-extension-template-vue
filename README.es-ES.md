# Vue 3 + Vite +Tailwindcss Extensions Template

### Crea rápidamente extensiones de Chrome en Vue.js y desarrolla con recarga en caliente sin necesidad de refrescar la extensión manualmente.

![Vue.js Chrome Extension Template images](docs/images/main.jpg)

### Structure Estructura

```
├── src
│   ├── assets 
│   ├── background.js // background runtime tiempo de ejecución
│   ├── components 
│   ├── content  // content-script tiempo de ejecución
│   │   └── content.js
│   ├── pages  
│   │   ├── popup  
│   │   │   ├── index.html
│   │   │   ├── index.js
│   │   │   └── index.vue
│   │   └── welcome
│   │     ├── index.html
│   │     ├── index.js
│   │     └── index.vue
│   ├── public
│   │   ├── images
│   │   │   ├── 128px.png  //logo
│   │   │   ├── 16px.png  
│   │   │   └── 48px.png
│   └── style.css
├── manifest.json  //archivo de manifiesto manifest.json
├── package-lock.json
├── package.json
├── postcss.config.js
├── tailwind.config.js 
└── vite.config.js
```

```bash
$ git clone  https://github.com/2322312693/chrome-extension-template-vue.git
$ npm install 
$ npm run dev
$ npm run build
```
